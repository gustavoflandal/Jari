# ADR-0002: Java 25 LTS e Spring Boot 4.1 com atualização anual

**Situação:** aceita (06/10/2026)

## Contexto
Restrição de plataforma Java/JavaScript; ecossistema maduro de assinatura digital e documentos; mercado de trabalho amplo. O Spring Boot não tem versão LTS (cerca de 12 meses de suporte por minor).

## Decisão
Java 25 LTS, Spring Boot 4.1. Todo contrato prevê janela de atualização de plataforma a cada 12 meses.

## Consequências
Virtual threads para fan-out de I/O sem programação reativa. Atualização anual vira custo recorrente de sustentação.
